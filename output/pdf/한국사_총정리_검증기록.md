# 한국사 총정리 검증 기록

검토일: 2026-10-26

## 검증 범위

- 기존 본문 47개 주제·351개 행을 읽고, 인물·연도·제도 및 문장 연결의 모호성을 검토했다.
- 의심되는 서술과 추가 내용은 국사편찬위원회 우리역사넷·한국학중앙연구원 자료로 대조했다. 모든 문장에 개별 출처를 붙인 전수 사료 대조는 아니다.
- 등록 기출 57~80회 1,200문항의 문제·선지·요약에서 용어 누락을 검색했다. 등장 횟수는 정답 출제 빈도와 다르므로 적중률로 해석하지 않는다. 원본 1,200문항의 모든 이미지·정답·해설을 다시 검증한 작업은 아니다.
- 최종 35쪽·355개 행: 원고와 PDF 추출문 일치, 54개 목차 링크, 47개 소제목 간격, 표 하단 경계, 유물 사진 44개와 표기 유지, 글자 깨짐, 용량을 검사했다.
- 전체 페이지 렌더를 검토했다. Apple SD Gothic Neo 유지. 파일 크기 4,483,490바이트(10MB 미만).

## 반영 내역

오류 정정, 혼동 방지를 위한 명료화, 누락 보완, 편집 정리를 함께 포함한다. 아래 항목 전체가 사실 오류였다는 뜻은 아니다.

- 선사 시대, 생활 도구로 구분하기 / 청동기: 계급·사유 재산, 벼농사 보급. 민무늬 토기·비파형 동검·거친무늬 거울·고인돌이 대표적이다.
- 선사 시대, 생활 도구로 구분하기 / 철기: 철제 농기구·무기 보급. 세형 동검·잔무늬 거울·거푸집, 명도전·반량전 등 중국 화폐 출토.
- 신라와 가야: 성장의 순서 / 내물·눌지: 내물: 김씨 왕위 세습 강화, 왜의 침입에 광개토 대왕의 지원. 눌지: 백제 비유왕과 나제동맹(433).
- 삼국 통일과 통일신라의 제도 / 토지·행정: 신문왕: 관료전 지급·녹읍 폐지, 9주 5소경 정비. 성덕왕: 정전 지급(722). 경덕왕: 녹읍 부활(757).
- 문벌 귀족과 무신 정권 / 무신정변(1170): 의종 때 정중부·이의방 등이 집권. 이의방·정중부·경대승·이의민을 거쳐 최씨 정권으로 이어졌다. 경대승은 도방을 설치했다.
- 사림의 성장과 네 차례 사화 / 사림의 등장: 성종 때 김종직 등 사림이 중앙 정계 진출. 중종 때 백운동 서원 설립. 이후 서원·향약을 기반으로 향촌 영향력을 넓혔다.
- 임진왜란과 두 차례 호란 / 임진왜란: 1592년 부산·동래 함락, 신립의 탄금대 전투, 김시민의 진주성 전투. 정문부의 북관대첩(1592~1593), 권율의 행주대첩(1593).
- 성리학과 실학 / 김장생: 호 사계. 가례집람, 예학 연구. 이이의 학문을 계승하고 송시열 등을 가르쳤다.
- 북학과 역사·지리 연구 / 유수원: 우서, 상공업 진흥과 직업적 평등을 주장했다.
- 독립협회·대한제국·국권 침탈 / 상권 수호: 황국중앙총상회(1898): 외국 상인의 침투에 맞서 상권 수호. 보안회(1904): 일본의 황무지 개간권 요구 저지.
- 독립협회·대한제국·국권 침탈 / 1907~1908: 1907년 헤이그 특사, 고종 강제 퇴위·한일신협약·군대 해산. 정미의병 확대, 13도 창의군의 서울 진공 작전(1908).
- 독립협회·대한제국·국권 침탈 / 대한제국(1897): 고종 황제 즉위, 대한제국·광무개혁, 구본신참. 양지아문·지계아문의 양전사업과 지계 발급, 상공업·교육 진흥. 대한국 국제(1899)로 황제권 강화. 원수부(1899)를 설치하여 황제의 군 통수권을 강화했다.
- 항일 의병과 의거 / 정미의병(1907): 고종 강제 퇴위·군대 해산 뒤 해산 군인 참여. 13도 창의군, 이인영·허위 등이 서울 진공 작전(1908)을 추진했다.
- 무장투쟁: 단체·인물·전투 / 1920년대 흐름: 봉오동(1920.6)·청산리(1920.10) 전투. 같은 해 10월부터 간도 참변. 이후 자유시 참변(1921), 미쓰야 협정(1925).
- 민족운동과 대중운동 / 근우회(1927): 민족주의·사회주의 계열 여성이 함께 결성. 여성의 지위 향상·민족 해방을 추구했다.
- 광복에서 정부 수립까지 / 미군정의 토지: 신한공사(1946): 동양척식주식회사 등 일본인 소유의 귀속 농지를 관리. 1948년 귀속 농지 분배가 추진되었다.
- 이승만 정부와 4·19혁명 / 장면 내각: 제2공화국: 의원내각제, 민의원·참의원의 양원제. 1961년 5·16 군사정변으로 무너졌다.
- 고려 문화: 인물·저술·유산 / 공예: 초기의 순청자, 상감 청자, 나전 칠기.
- 국외 독립운동: 만주·연해주 / 강제 이주(1937): 소련 당국이 연해주의 한인들을 중앙아시아로 강제 이주시켰다.
- 일제강점기의 문학·노래·도시 생활 / 영화·대중가요: 나운규의 아리랑(1926), 윤심덕의 사의 찬미(1926).
- 유물 도판 제목을 삼국·남북국으로 넓혀 통일신라·발해 유물이 포함된 범위를 정확히 표시했다.
